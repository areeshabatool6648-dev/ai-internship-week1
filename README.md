\# AI Internship - Week 1



Week 1 work: prompting experiments, LLM API calls via OpenRouter, chat loop with memory, error handling, and git branching practice.



\## Structure

\- `day2\_json.py` / `day2\_fewshot.py` — prompting experiments (JSON output, few-shot)

\- `chat.py` — first API call script

\- `day3\_chat\_loop.py` — chat loop with message history (memory)

\- `config.py` — holds SYSTEM\_PROMPT

\- `day4\_error\_handling.py` — chat loop with try/except error handling



\## Setup

1\. Create a `.env` file with `OPENROUTER\_API\_KEY=your\_key\_here`

2\. Install dependencies: `pip install openai python-dotenv`

3\. Run: `python day3\_chat\_loop.py`
