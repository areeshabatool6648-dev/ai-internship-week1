# Customer Feedback Intelligence

## product_docs

These files contain information about DeskNest, including booking, billing, team accounts, operators, customer support, and other parts of the product.

They provide useful product context when interpreting customer feedback.

## customer_feedback

`desknest_customer_feedback.csv` contains the customer feedback used in this project.

Each row has a unique feedback ID along with information such as customer segment, channel, region, rating, and the original comment. The dataset contains complaints, feature requests, positive feedback, mixed feedback, and comments that may not fit neatly into one theme.

Keep the feedback IDs attached to findings so the original rows behind a theme can be checked.

The feedback file is the customer dataset provided for searching, grouping, counting, and comparing. The product docs are background information for interpreting what customers mean.

The product docs provide background information about DeskNest and how the product works.
