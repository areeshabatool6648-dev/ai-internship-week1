# AI Lesson Pack Generator

This folder contains the course and teaching material used for the lesson-pack project.

## curriculum_docs

These files contain subject content, teaching guidance, assessment guidance, sample lessons, differentiation advice, and worked examples that can be used when creating a lesson.

The material covers several subjects and topics, including computing, mathematics, statistics, science, and business communication.

The curriculum docs are the subject content and teaching references provided for producing lesson packs. Use the examples and guidance alongside the relevant subject material.

## sample_requests.json

This file contains a few example lesson requests.

The generated lesson should stay grounded in the supplied course material. If the requested topic is not covered by the supplied documents, the application should handle that clearly rather than inventing course content.
