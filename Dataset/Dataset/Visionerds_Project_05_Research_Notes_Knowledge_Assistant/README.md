# Research Notes / Knowledge Assistant

## notes

This folder contains technical notes on prompting, model APIs, embeddings, vector search, RAG, conversation memory, query rewriting, tool calling, routing, FastAPI, SQLite, testing, Git, and CI.

These notes are the source material for the assistant. The assistant should answer from the supplied notes and show which source material was used.

Some questions may use different wording from the notes, and some follow-up questions may depend on the earlier conversation.

If the notes do not cover a question, the application should handle that clearly instead of inventing a source.

The notes are the technical source material provided for the assistant. They cover both core concepts and practical engineering examples.

## sample_questions.json

This file contains a few example questions that can be used when testing the application.

The notes are the technical source material the assistant should search and answer from.
