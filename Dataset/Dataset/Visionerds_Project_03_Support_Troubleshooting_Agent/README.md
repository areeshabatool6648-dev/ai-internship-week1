# Support Troubleshooting Agent

This project contains two types of information.

## docs

These files explain how ParcelPilot works, what the services do, what the error codes mean, and how common problems are normally investigated.

Use these documents when the assistant needs product or troubleshooting knowledge.

## system_data

These files describe the current state of the fictional ParcelPilot system. They include service status, configuration, carrier information, logs, and previous incident records.

The documentation explains how the system is supposed to work. The system data shows what is happening in the system.

A troubleshooting answer should be based on the evidence available in these files. If the available information is not enough to identify a cause, the application should say what is still unknown and suggest the next useful check.

The docs are the information about how ParcelPilot works and how common problems are investigated. The system data is the current service status, configuration, logs, carrier information, and incident history used during an investigation.
